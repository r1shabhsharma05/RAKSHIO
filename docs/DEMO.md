# RAKSHIO — Demo Script (3 minutes, record 29 Nov)

Record on a phone, screen recording, Judge Mode (no mic needed).
One continuous take. Speak Hindi/Hinglish, slowly, like talking to a
worried parent — not like a pitch.

## 0:00–0:20 — Panic screen
- Open the app. "Fraud hua hai. Ghabrana nahi — pehla kadam ye hai."
- Show the banner: "RAKSHIO report file nahi karta."
- Tap **Judge Mode → Seeded scenario chalao** (₹20,000 UPI story loads).

## 0:20–0:50 — Confirmation gate
- Confirm screen: "RAKSHIO ne ye samjha — rashi ₹20,000, kal subah 10 baje, UPI, HDFC."
- Tap **Haan, sahi hai** three times. "Galat hota to yahin sahi karte. Card tabhi lock hota hai jab aap haan kehte hain."
- Tap **Ye sahi hai — aage badhein**. Incident card + timeline appear.

## 0:50–1:20 — Golden Hour Clock + 1930 Call Coach
- "Aage ke kadam": show the live clock — 1930 turant, behtar pehle 4 ghante me; portal 1930 call ke 24 ghante ke andar; bank 3 working days me suchit karein.
- Open **1930 Call Coach**: the 30-second script is already written from the confirmed facts. "Call karne se pehle script padh lijiye."
- Show the checklist. Do NOT actually call 1930 on camera.

## 1:20–2:00 — Evidence Vault + tamper test
- Open **Evidence Vault**. Add the fraud SMS as evidence.
- Tap **Chain verify karein** — green: "Chain sahi hai."
- Tap **Tamper test** — red: "Chain TOOTI — record #1 badla gaya hai." "Saboot badla to pata chal jata hai."

## 2:00–2:30 — Second-Scam Shield
- Open **Second-Scam Shield**. Paste: "Recovery agent hoon, paisa wapas karwa dunga, pehle fee bhejo."
- Truth Card turns red: "KHATRA". Read one red flag aloud. "Recovery agent aksar dusra scam hota hai."

## 2:30–3:00 — Proof Pack + close
- Open **Proof Pack**. Show the root hash QR. Download the PDF.
- Close, to camera: "RAKSHIO report file nahi karta — woh aapko karna hota hai. Lekin pehle ghante me sahi kadam uthana ab aasan hai. Panic me bhi, sahi kadam."

## Recording notes
- Do not call 1930, any bank, or file any real complaint during the demo.
- The seeded scenario is demo data — say so once, on camera, at 0:20.
- Keep the phone in portrait; the app is mobile-first (max-width 28rem).
- If speech recognition is unavailable in the recording browser, use Judge Mode (no mic) — that is what it is for.
